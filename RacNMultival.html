La racine n-ième multivaluée

Pour z ≠ 0 fixé, l'ensemble \sqrt[{n}]{z} compte n valeurs, réparties cycliquement. Cet outil affiche, pour un point z que vous déplacez librement, ses n racines n-ièmes selon la détermination canonique (argument choisi dans [0, 2π[) — une couleur par détermination.

Avec cet outil, vous pouvez :

  • choisir n (de 2 à 6) au sélecteur ;
  • déplacer z librement dans le plan de gauche (cliquer-glisser, ou simplement cliquer ailleurs) ;
  • observer les n racines se déplacer dans le plan de droite, chacune laissant une traînée colorée qui s'efface en 3,5 secondes.

Faites traverser à z l'axe réel positif (la coupure de la détermination canonique) : les couleurs des racines sautent d'une position à l'autre, alors que l'ensemble des racines, lui, se déplace continûment. Ce n'est pas un défaut de l'outil : c'est exactement la discontinuité de la détermination canonique décrite dans le texte — et la raison pour laquelle un suivi continu le long d'un chemin (voir l'autre applet, sur le redressement) demande un traitement différent.
